## 시작하기

### 1. 저장소를 클론합니다.

```bash
git clone https://github.com/younyikim/younyikim-playground.git
```

### 2. 의존성을 설치합니다.

```bash
pnpm next-template install
```

### 3. 개발 서버 실행

```bash
pnpm next-template dev
```
